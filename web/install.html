安装向导

填好下面这些信息，程序会自己建库、建表、创建管理员，然后重启生效。

数据库（MariaDB / MySQL）

强烈建议用专用子账号而不是 root：权限只给到这一个库，拖库撞库也伤不到别人。 先在数据库里执行下面三句（用 root 或 DBA 账号），再回来填表。

建库 + 建子用户 SQL（点开复制） 
CREATE DATABASE IF NOT EXISTS kongyu
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'kongyu'@'localhost' IDENTIFIED BY '换成强密码';
CREATE USER IF NOT EXISTS 'kongyu'@'127.0.0.1' IDENTIFIED BY '换成强密码';

GRANT ALL PRIVILEGES ON kongyu.* TO 'kongyu'@'localhost';
GRANT ALL PRIVILEGES ON kongyu.* TO 'kongyu'@'127.0.0.1';
FLUSH PRIVILEGES;
管理员账号（写作后台用）
站点信息（留空用默认，之后写进 SEO 与页面）

安装成功后 config.json 会写在程序旁边（0600 权限），请自行备份。
